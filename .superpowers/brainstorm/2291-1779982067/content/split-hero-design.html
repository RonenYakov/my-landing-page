How it works

Background split (behind laptop)

  • Left half: dark #0d1117 — AI atmosphere
  • Right half: white #f9f9f9 — full-stack atmosphere
  • Divider tracks mouse X with spring (stiffness 60, damping 18)
  • Clamped 20–80% so extremes don't fully hide either side
  • Floating code snippets on each side fade in/out

Laptop screen (center object)

  • Left half: confusion matrix + classification report (real screenshots)
  • Right half: social platform UI (real screenshot)
  • Internal screen divider also moves with mouse (same spring value)
  • Screenshots placed in /public/hero/ — no external deps
  • Laptop frame: 320–380px wide, centered, drops shadow on bg
